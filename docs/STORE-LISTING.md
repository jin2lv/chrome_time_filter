## 2. 详细描述（可直接粘贴）

```
时光机（TimeMachine）是一款浏览器扩展，让你在社交媒体和社区论坛上只看到
指定时间点「之前」发布的帖子，把设定时间「之后」的内容自动过滤掉。

【解决什么】
· 投资噪音隔离：股票社区（雪球、同花顺）盘中实时帖子 90% 是情绪噪音。
  开盘前设一个「昨日 0 点」，盘中刷到的就只有昨天及之前的冷静讨论。
· 事前 / 事后切割：暴跌后满屏「我早就说了」，用时光机屏蔽事后内容，
  只留下真正的盘前观点。

【核心功能】
· 截止模式：只显示发帖时间 ≤ 你设定的截止点的帖子。
· 雪球虚拟分页：跨原生页面按需收集符合时间条件的帖子，重新组成连续列表。
· 雪球六类覆盖：全部、讨论、投资者关系、交易、资讯、公告切换后分别过滤。
· 两种过滤策略：隐藏（彻底不显示）/ 折叠（收起为占位条，可点开看）。
· 实时过滤计数器：图标角标与面板显示当前页已过滤多少条。
· 评论过滤：帖子详情页的评论按各自时间戳独立判定。
· 快捷开关：点图标开面板，或快捷键 Alt+Shift+T 一键切换（可在 chrome://extensions/shortcuts 自定义）。
· 按需授权：安装时不申请任何站点权限，首次访问某平台才请求。
· 适配包热更新：平台改版自动拉取最新选择器配置（可关闭）。
· 失效保护：平台改版导致适配失效时，不过滤并弹出提示，绝不让你误以为「没新帖」。

【隐私】
· 不收集、不上传任何用户数据，全部过滤在本地完成。
· 仅从公开静态托管（GitHub Releases + jsDelivr）拉取适配包配置，不携带用户标识。

【当前支持】
· 雪球（xueqiu.com）、同花顺（t.10jqka.com.cn）
· 更多平台（股吧、豆瓣等）正在路线图中；不适合深度回溯的信息流不会勉强适配。
```

> ⚠️ 上架口径：集思录（jisilu.cn）与东方财富资讯（finance.eastmoney.com）适配包已内置（2026-08-18），但仅单快照取证、未过真机验收——**上架文案暂不列入上述支持清单**；P2-16 验收通过后在「当前支持」补这两行，并保持「平台 + 页面类型 + 能力」粒度（见 DEV-PLAN P2-22）。

## 5. 隐私政策 URL 托管建议

Chrome Web Store **强制要求**填写可公开访问的隐私政策链接。可选方案：
1. 在 GitHub 仓库放 `PRIVACY-POLICY.md`，用仓库的 raw / Pages 链接；
2. 用 Gist 公开快照；
3. 自行托管一个静态页。

> 注意：本扩展**无后端、无账号、无数据上报**，隐私政策核心即声明上述三点，审核通常无障碍。
