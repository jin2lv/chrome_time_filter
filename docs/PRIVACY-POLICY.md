# 时光机（TimeMachine）隐私政策

**生效日期**：2026-08-11
**适用范围**：时光机浏览器扩展（Chrome / Edge，Manifest V3）v1.0.0 及后续版本。

---

## 1. 我们收集什么

**什么都不收集。**

时光机不收集、不上传、不分析任何个人数据或使用数据。我们没有后端服务器、没有账号体系、没有数据分析 SDK，也不嵌入任何第三方追踪脚本。

## 2. 数据存储在哪里

所有数据仅保存在你本地浏览器的 `chrome.storage.local` 中，包括：

- 你为各网站设定的「截止时间 / 过滤策略」等配置；
- 适配包配置（内置兜底 + 可选远程更新）；
- 你的偏好设置（默认策略、角标开关等）。

这些数据**不会**离开你的设备，也不会被我们或任何第三方读取。

## 3. 权限说明

| 权限 | 用途 | 是否上传数据 |
|------|------|------------|
| `storage` | 在本地保存你的过滤配置 | 否 |
| `activeTab` | 仅在你主动打开扩展面板时识别当前标签页，以显示站点状态并启动已授权站点的过滤脚本 | 否 |
| `scripting` | 动态向已授权网站注入内容脚本以执行过滤 | 否 |
| `alarms` | 每 12 小时触发一次适配包更新检查 | 否 |
| `optional_host_permissions`（雪球、同花顺） | 仅在你首次访问对应网站并主动授权后，才对该网站执行过滤 | 否 |

我们采用**按需授权**模型：安装扩展时不申请任何网站权限；只有你访问某平台并点击「授权」后，扩展才会对该平台生效。你可以随时在设置页撤销授权。

## 4. 适配包更新（唯一的外网请求）

为了在低维护成本下应对平台改版，时光机会**每隔 12 小时**（以及安装时）从公开静态托管拉取最新的适配包配置：

- 来源：公开的 GitHub Releases，经 jsDelivr CDN 加速；
- 内容：仅为平台的选择器与时间解析规则（JSON 配置），**不含任何用户标识**；
- 失败处理：拉取失败或校验不通过时**静默降级**到内置兜底版本，不弹警告、不上报；
- 可关闭：你可以在设置页关闭「适配包自动更新」，此后仅使用内置适配包。

该请求不携带你的身份、浏览历史或任何可识别信息。

## 5. 我们不与第三方共享数据

由于我们不持有任何用户数据，因此不存在与任何第三方共享、出售或交易数据的情况。

## 6. 儿童隐私

时光机不面向儿童，也不明知地收集儿童数据。

## 7. 政策变更

若未来版本引入任何数据收集行为，我们将更新本政策并在扩展更新说明中显著提示。

## 8. 联系我们

当前版本未在扩展设置页内提供反馈入口；联系方式以 Chrome Web Store 商品详情页公布的支持渠道为准。

---

*一句话总结：时光机不收集任何用户数据，所有过滤功能都在你的浏览器本地运行；仅从公开静态托管拉取适配包配置，且不携带任何用户标识。*
